## Install

Run as `root` on a Variscite board with Docker, curl, and systemd:

```sh
curl -kfsSL https://github.com/dorta/var-scope/raw/main/install.sh | sh
```

## Commands

```sh
var-scope status
var-scope version
var-scope url
var-scope start
var-scope stop
var-scope restart
var-scope logs
var-scope upgrade
var-scope uninstall
var-scope uninstall --yes
```
